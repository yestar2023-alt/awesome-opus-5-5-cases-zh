## 尝试与复现

检查程度：有复现文档

1. 准备 README 指定的 Node.js 20.19+ 或 22.12+ 和 npm，取得仓库后阅读 package.json。
2. 按 README 运行 npm ci、npm run dev，再打开 http://127.0.0.1:5173；纯前端模式用 npm run dev:static。
3. 对照玩法说明检查采集、建造、AI 对局；联机和 SDK 需另测。
